# NeseritUserHunter — Инструкция по деплою на Amvera Cloud (.git)

Данный репозиторий полностью подготовлен для автоматической сборки и захода на облачный хостинг **Amvera Cloud** через `git push`.

---

## 🚀 Что уже подготовлено в проекте:

1. **`amvera.yml`** — официальный файл конфигурации Amvera.
2. **`Dockerfile`** — готовый универсальный Docker-образ (для сборки через Docker в Amvera).
3. **Авто-переменные порта (`process.env.PORT`)** и динамическое связывание `0.0.0.0`.
4. **Персистентность данных (`/data`)** — сессии пользователей, промокоды и администраторы сохраняются во внешнем хранилище `/data`, не сбрасываясь при обновлениях контейнера.

---

## 📋 Инструкция по заливу на Amvera Cloud через Git

### Шаг 1. Создание проекта на Amvera
1. Войдите в личный кабинет [Amvera Cloud](https://amvera.ru).
2. Нажмите **«Создать проект»**.
3. Укажите имя проекта (например: `neserit-user-hunter`).
4. В типе сервиса выберите **«Приложение»**.
5. Выберите тип сборки **«Сборка из Git (Node.js или Docker)»**.

---

### Шаг 2. Настройка Переменных Окружения (Environment Variables)
В настройках проекта на Amvera зайдeте во вкладку **«Переменные»** и добавьте:

- **`TELEGRAM_BOT_TOKEN`** — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather) (например: `8868659501:AAHK7Ke00c5BLr90QZ8r_rpMIzanpyKUnaA`).
- **`GEMINI_API_KEY`** — API-ключ Gemini для работы AI-генератора и AI-админки.
- **`NODE_ENV`** — со значением `production`.
- **`ADMIN_TELEGRAM_ID`** *(опционально)* — ваш Telegram ID (число) для автоматической выдачи прав супер-администратора.
- **`PROXY_URL`** *(опционально)* — URL вашего HTTP/SOCKS5 прокси (например `http://user:pass@ip:port`), если хотите полностью изолировать IP сервера от проверок Telegram/Fragment.

## 🛡️ Встроенная система защиты от блокировок IP (Anti-IP Block System)

В боте реализован многоуровневый stealth-движок для защиты IP вашего сервера:

1. **Ротация User-Agent и заголовков браузера**: Каждый запрос генерирует случайный заголовок реального браузера (Chrome 122, Safari 17, Firefox 123 на Windows/Mac/Linux/Android) со всеми сопутствующими `Sec-Ch-Ua` и `Accept-Language` заголовками.
2. **Семафор ограничений частоты (Concurrency Limiter & Jitter)**: Параллельные сетевые запросы ограничены максимумом 4 одновременно с добавлением рандомных микро-задержек (20-80 мс), предотвращая пиковую нагрузку на Telegram и Fragment.
3. **Автоматический Предохранитель (Circuit Breaker)**: Если Telegram или Fragment ответит статусом `429 Too Many Requests` или `403 Forbidden`, движок временно приостановит внешние запросы на 10 секунд и вернет безопасные ответы из кэша, чтобы IP не попал в блэклист.
4. **Интеллектуальное кэширование (In-Memory Cache)**: Результаты проверок кэшируются на 10-15 минут, исключая повторные сетевые запросы для одинаковых юзернеймов.
5. **Поддержка Прокси (HTTPS/SOCKS Proxy)**: При указании переменной `PROXY_URL` все запросы к Telegram/Fragment будут идти через сторонний прокси-сервер.

### Шаг 3. Загрузка кода через Git

Откройте терминал в папке проекта и выполните команды:

```bash
# 1. Инициализация Git (если репозиторий еще не создан)
git init

# 2. Индексация всех файлов
git add .

# 3. Фиксация изменений
git commit -m "Initial release for Amvera Cloud"

# 4. Добавление Amvera Remote (ссылка берется из панели Amvera)
git remote add amvera https://git.amvera.ru/ВАШ_ЛОГИН/ИМЯ_ПРОЕКТА.git

# 5. Отправка кода и запуск автодеплоя
git push amvera master
# (или `git push amvera main`, если ветка называется main)
```

---

## 📊 Мониторинг и статус
После команды `git push amvera master`:
1. Amvera автоматически начнет сборку (`npm install && npm run build`).
2. После сборки запустится команда `npm start` (`node dist/server.cjs`).
3. Бот сразу выйдет в сеть и начнет отвечать на сообщения в Telegram 24/7!
